### Самая важная идея security для Девопс: мы стараемся уменьшить количество способов, которыми можно атаковать сервер, и ограничить последствия, если что-то все-таки реально случится. 

Например, если на сервере установлено 50 ненужных сервисов, то каждый из них потенциально может содержать уязвимость. Поэтому существует принцип:
не нужно - не устанавливаем / отключаем 

Также и с портами:
нужен для ssh - 22
http - 80
https - 443

остальные закрываем

И с пользователями:
обычному пользователю не нужен root
значит не даем root
для отдельных действий используем sudo 

То есть весь handering строится на идее "least privillege" - минимально необходимые права

То есть важно:
- регулярно устанавливать security updates
- устанавливать только необходимые пакеты
- вести логи и мониторинг
- шифровать чувствительные данные
- делать backups и проверять восстновление
- использовать ssh-keys вместо паролей и тд

Есть еще 2 нюанса: смена ssh-порта на нестандартный может уменьшить количество автоматических сканирований, но сама по себе серьезной зашитой не является. 

### ACL

Например, у нас есть файл, который принадлежит Alex. У группы developers на этот файл права r--, а у остальных пользователей - вообще нет прав. Я хочу дать права на этот файл пользователю elizaveta, но при этом не добавлять ее в группу developers.

И вот здесь обычных chmod недостаточно. И здесь появляется ACL.

***setfacl -m u:elizaveta:rw document.txt***

То есть ACL позволяет дать индивидуальные права поверх стандартных user, groups, other.

Основные команды, которые стоит понимать:
- getfacl document.txt - посмотреть существующие ACL
- setfacl -m u:alex:rw document.txt -тут  m-modify, добавить права пользователю
- setfacl -x u:alex dociment.txt - удалить конкретную ACL-запись. 
- setfacl -R -m u:john: rw project/ - рекурсивно для директории, то есть мы добавляем права на директорию, и на то, что находится внутри

Но также есть такое понятие как ***mask*** - она задает максимальные права для ACL-пользователей и групп.

Например, ACL говорит alex -> rwx, а mask говорит r--, тогда максимальные права для alex будут r--. 
То есть маск в своем роде потолок разрешений ACL. 

Mask задается так:
- setfacl -m m::r-x document.txt - то есть здесь максимальные права на файл read и execute
