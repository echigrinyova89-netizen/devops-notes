### Что такое маршрутизация?

Маршрутизация - это выбор пути, по которому IP-пакет должен попасть до сети назначения.

Ключевая мысль: routing работает на 3 уровне.

То есть маршрутизатор смотрит прежде всего на:
destination IP - адрес устройства, которому адресован пакет и сверяет его со своей routing table.

Какие таблицы здесь участвуют:
1. ARP Table - нужна, чтобы понять, какой MAC соответствует конкретному IP в локальном сегменте.
IP -> MAC

2. MAC Addressed Table - ее использует switch, чтобы понимать, в какой физический порт отправить Ethernet frame
MAC -> Switch port 

3. Routing table - куда отправить пакет, отвечает за выбор маршрута между сетями
Network -> interface / next hop 

Default gateway (основной шлюз) - дверь на выход из локальной сети во внешний мир (в интернет или другие сети). Чаще всего обычный роутер или маршрутизатор.

Главное правило: комп обращается к default gateway только когда понимает, что нужный destination ip находится вне его собственной подсети. 

Для отправки Ethernet frame хосту нужен MAC адрес роутера.
Хост делает ARP запрос: у кого такой ip address?

Происходит broadcast - отправляем запрос сразу всем устройствам, мы же не знаем, чей это ip.
И затем роутер отвечает нашему хосту, что это его ip address.

**ВАЖНО**

При передаче данных: 
Destination IP - IP конечного устройства, куда пакет должен попасть в итоге.
Destination MAC - MAC СЛЕДУЮЩЕГО УСТРОЙСТВА на текущем участке сети.
